# TODO List TUI (Go + Bubble Tea)

This is the fourth step in the **Go TUI Learning Roadmap**.  
It demonstrates a minimal **Text User Interface (TUI)** application using [Bubble Tea](https://github.com/charmbracelet/bubbletea).

---

## 📌 What It Does
- Navigate through a list of to do items
- Add new to do items (entering in edit mode)
- update todo items as done
- Concepts: layout basics, navigation, storing and updating items.
