# Hello World TUI (Go + Bubble Tea)

This is the very first step in the **Go TUI Learning Roadmap**.  
It demonstrates a minimal **Text User Interface (TUI)** application using [Bubble Tea](https://github.com/charmbracelet/bubbletea).

---

## 📌 What It Does
- Displays a simple message in the terminal:  

Hello World TUI!
Press any key to exit.

- Exits when any key is pressed.
- Serves as a starting point to confirm that Go and Bubble Tea are installed and working correctly.
