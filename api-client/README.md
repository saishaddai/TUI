# API Client TUI (Go + Bubble Tea)

This is the sixth step in the **Go TUI Learning Roadmap**.  
It demonstrates a minimal **Text User Interface (TUI)** application using [Bubble Tea](https://github.com/charmbracelet/bubbletea).

---

## 📌 What It Does
Displays a promtp to add an URL in the terminal:  

- Add an specific API URL following the example.
- Retrieves the informatio in there and shows the response (a JSON text) in terminal.
