# File Explorer TUI (Go + Bubble Tea)

This is the last step in the **Go TUI Learning Roadmap**.  
It demonstrates a minimal **Text User Interface (TUI)** application using [Bubble Tea](https://github.com/charmbracelet/bubbletea).

---

## 📌 What It Does
- Dynamic rederize: Redrawing panels with updated data.
- Layouts: Organise metrics in screen.
- Colors and styles: Use libraries like lipgoss to provide vusual formatting.
- Periodic events: Manage messages to refresh UI.
