# Counter TUI (Go + Bubble Tea)

This is the second step in the **Go TUI Learning Roadmap**.  
It demonstrates a minimal **Text User Interface (TUI)** application using [Bubble Tea](https://github.com/charmbracelet/bubbletea).

---

## 📌 What It Does
Displays a simple counter in the terminal:  

- Increment/decrement a number using arrow keys.
- Concepts: state management, dynamic rendering.
