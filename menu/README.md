# Menu TUI (Go + Bubble Tea)

This is the third step in the **Go TUI Learning Roadmap**.  
It demonstrates a minimal **Text User Interface (TUI)** application using [Bubble Tea](https://github.com/charmbracelet/bubbletea).

---

## 📌 What It Does
- Navigate through a list of options with arrow keys.
- Select an option with Enter.
- Concepts: layout basics, navigation.
